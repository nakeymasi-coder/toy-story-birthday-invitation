# Mason's Toy Story Birthday Invitation 🤠🚀

A fully interactive Toy Story birthday invitation — **Mason is turning 5!**

**Live:** https://nakeymasi-coder.github.io/toy-story-birthday-invitation/
**Party:** Saturday, November 14, 2026 · 2–5 PM · Mason's House

## What's inside
- 🎬 **NOW SHOWING** cinema section with the official Toy Story trailer embedded from YouTube
- 🚪 **ANDY'S COMING!** — the toys flop down and freeze, plus surprise freeze moments and a saved-the-toys counter
- 🧸 Tappable stage toys with signature moves and speech-bubble lines (no robot voices)
- 🔎 Hidden Toy Hunt — find all 5 hidden toys and earn the Sheriff Badge
- 🕹️ Pizza Planet Claw game — rescue all 3 aliens
- 💃 Dance Party with real music, live countdown, party plan and an RSVP reply-card builder

Installable as an app (Add to Home Screen) with its own name, icon and manifest.

*Demo invitation — party name/date/details are swappable for a real party.*
